# 初めてのPython — AI時代の第一歩（カリキュラム骨子）

## コンセプト
プログラミング未経験でも、**7日で Python の基礎を身につけ、「AI を自分のコードから動かす」ところまで**到達する。

- **AIネイティブ入門**：初日から「AIに聞きながら書く」「LLM API を叩く」を織り込み、AI時代の作り方そのものを学ぶ
- **既存 Bootcamp と同じ思想**：実装は AI に任せられる前提。人間側に必要な **「読める・直せる・説明できる」** に振り切る
- **面接/実務でも通用**：各項目に「実務ではこう使う」「AIにはこう指示する」を併記
- **登録不要・進捗はブラウザ保存**（Laravel版と同じ体験）

対象：非エンジニア／文系／これからAIを仕事に使いたい人／エンジニア転向の第一歩

## Day別の中身（骨子）

### Day 0：なぜ今Python／挫折しない始め方
- Pythonが「AIの共通語」である理由（PyTorch/LangChain/データ/自動化）
- 環境構築で消耗しない：まずは**ブラウザ実行**（Google Colab / オンライン実行）から
- AI時代の学び方：**エラーは友達**。エラー文をそのままAIに貼る流儀
- 「AIに聞く」型：良い質問・悪い質問（文脈・期待する出力を添える）

### Day 1：変数・型・入出力（データの器）
- 変数＝名前つきの箱／代入
- 基本の型：`str` `int` `float` `bool`／型を意識する理由
- `print()` と `input()`／f-string での組み立て
- 実務：設定値・APIキーを変数で管理する感覚
- AIに聞く例：「この変数の型が何になるか説明して」

### Day 2：条件分岐・ループ（判断と繰り返し）
- `if / elif / else`／比較・論理演算子
- `for` / `while`／`range`／`break` `continue`
- インデント＝Pythonの構造（ここでつまずく人が多い）
- 実務：一覧データを1件ずつ処理する（AI出力の後処理の基礎）
- 悪い例/良い例：ネストが深いコード → 早期return的な整理

### Day 3：リスト・辞書（まとめて扱う）★AIとの接点
- リスト（順序）／辞書（キーと値）／ネスト
- **なぜ重要か：AIの入出力（JSON）はほぼ「辞書とリスト」**
- 内包表記の"読み方"（書けなくていい、読めればいい）
- 実務：APIレスポンスから欲しい値を取り出す
- AIに聞く例：「このJSONから◯◯を取り出すコードを書いて」＋自分で検算

### Day 4：関数・モジュール（再利用と部品化）
- `def`／引数・戻り値／デフォルト引数
- なぜ関数にするか（重複排除・テスト・説明しやすさ）
- `import`／標準ライブラリ／pip の存在（`requests` 等）
- 実務：処理を「入力→出力」の部品として設計する
- AIに任せる/自分でやるの線引き（設計は人、実装はAI）

### Day 5：ファイル・API連携（外の世界とつながる）
- ファイル読み書き（`with open`）／CSV・JSONの基本
- HTTPと `requests`：GET/POST、ステータスコード、`.json()`
- APIキーの扱い（`.env` / 環境変数、コードに直書きしない）
- 例外処理 `try/except`（AI/ネットワークは失敗する前提）
- 実務：外部データ取得 → 整形 → 保存の流れ

### Day 6：AIを動かす（この教材の看板）★
- LLM API の考え方（プロンプト＝入力、応答＝出力、トークン/料金）
- OpenAI / Anthropic どちらでも動く最小コード（`requests` or SDK）
- ミニ実装：**「文章を要約する」「問い合わせを分類する」ツール**
- プロンプト設計の基礎（役割・制約・出力形式を指定）
- 安全面：APIキー管理、ハルシネーション、結果の検算
- AIに聞く例：「このプロンプトを、出力をJSON固定にするよう改善して」

### Day 7：小さく作って完成させる（実践）
- 題材：**AI要約ツール** or **簡易AIチャット**（1ファイルで完結）
- 「小さく作る」設計：入力→AI→整形→表示 の一直線
- 動かして直す：エラーをAIと潰すループの体験
- 公開の選択肢の紹介（Colab共有／簡単なWebアプリ化＝次のTS編へ橋渡し）
- 卒業チェック：自分の言葉で「何を作ったか・なぜこの設計か」を説明

## 付随コンテンツ（Laravel版と同じ枠組み）
- **用語集**：Python用語（型/リスト/辞書/内包表記/例外/仮想環境…）＋ AI用語（LLM/プロンプト/トークン/API/JSON/ハルシネーション…）

- **理解度チェック**：4択＋記述（記述は模範解答＋「実務ではこう言う」）
- **ダッシュボード**：進捗・ストリーク・正答率（localStorage）
