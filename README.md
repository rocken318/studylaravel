# Laravel Bootcamp — 7日間で面接を突破する学習アプリ

Laravel 未経験者が **1週間で「Laravel を使ったチーム開発」の面接を突破できるレベル** の知識を身につけるための学習 Web アプリです。

このアプリが最優先するのは「実装力」ではなく、**設計思想を自分の言葉で説明できること**。
実装は AI に任せられる前提で、人間側に求められる「判断」と「説明」に振り切っています。

## コンセプト

- **「何ができるか」ではなく「なぜそう設計するのか」** を学ぶ
- すべてのレッスン・用語・想定問答に **「面接ではこう言う」** の言い換え例を用意
- **悪い例 / 良い例** を対比で提示
- ダミーテキストなし。実コンテンツを書き切っています

## 主な機能

| 機能 | 内容 |
| --- | --- |
| **Day 0:PHP速習** | PHP未経験でもLaravelのコード例を読めるように、最低限のPHP(変数・連想配列・関数/アロー関数・クラスとOOP・`->`と`::`・名前空間・型宣言)を先頭に用意。各レッスンに「Laravelではこう出てくる」を明記 |
| **7日間カリキュラム** | Day単位で章立て。各Dayに4〜5レッスン。概念 → なぜ → コード例 → 面接での言い換え、の構成。完了チェック付き |
| **例えるなら(身近な具体例)** | 抽象的な設計論を日常の例えに翻訳して各レッスン上部に表示。「広告枠申込サイトならこの部分」の対応例も添える |
| **AIに聞くボタン** | レッスン/設問/面接問答/用語から、その文脈に合った質問文を自動生成してChatGPT/Claudeを新タブで開く(質問はコピー済み)。APIキー・課金不要 |
| **理解度チェック** | 各レッスンに4択・記述式の設問。記述式は模範解答と面接での言い換え例を表示 |
| **面接想定問答集**(主役) | 設計思想 / 責務分離 / DB設計 / 性能 / チーム開発 / 自己経験 の6カテゴリ。NG回答・加点回答・「なぜ差がつくのか」を併記。自分の回答を保存でき、暗記モード(カードめくり)も搭載 |
| **実務用語集** | Fat Controller / N+1問題 / 冪等性 / 悲観ロック・楽観ロック など 41語。検索・カテゴリ絞り込み。レッスン本文中の用語をクリックするとモーダルで解説 |
| **ダッシュボード** | 全体進捗、学習ストリーク(連続学習日数)、クイズ正答率、面接カードの習得数、今日やるべきDay、苦手な問題、今日の一問、Day別の進捗バー |
| **復習モード** | 間違えた問題だけを再出題 |

学習進捗・回答はすべて **ブラウザの localStorage** に保存されます(サーバー・DB不要)。

## カリキュラムの内容

0. **Day0** — Laravelを読むための最低限PHP(変数・連想配列・関数・OOP・名前空間・型)
1. **Day1** — MVCとリクエストライフサイクル、Laravelを選ぶ理由
2. **Day2** — ディレクトリ構造、artisan、マイグレーションの思想
3. **Day3** — ルーティングとコントローラー、ルートモデルバインディング
4. **Day4** — Eloquentとリレーションと N+1 問題
5. **Day5** — バリデーション(FormRequest)、ミドルウェア、Blade
6. **Day6** — 責務の分離(Service層)、トランザクションと排他制御
7. **Day7** — チーム開発の作法(Gitフロー、PSR-12、テスト、.env、レビュー)

## 技術スタック

- **Next.js 14**(App Router) + **TypeScript**
- **Tailwind CSS**
- コンテンツはすべて TypeScript オブジェクトとして `src/data/` に静的定義(DB・API なし)
- 進捗と回答は **localStorage** に永続化
- **Vercel** にそのままデプロイ可能

## セットアップ手順

前提: Node.js 18.17 以上(推奨 20+)

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動(http://localhost:3000)
npm run dev

# 本番ビルド
npm run build

# 本番サーバー起動
npm start
```

## Vercel へのデプロイ手順

1. このリポジトリを GitHub にプッシュする
2. [Vercel](https://vercel.com/) にログインし **Add New... → Project** を選択
3. 対象の GitHub リポジトリ(`studylaravel`)を Import
4. フレームワークは自動で **Next.js** と認識されます。設定はデフォルトのままで OK
   - Build Command: `next build`
   - Output: 自動
   - 環境変数の設定は不要(DB・API を使わないため)
5. **Deploy** を押すと数分で公開されます

以降、GitHub の該当ブランチに push するたびに自動で再デプロイされます。
